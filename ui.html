Quick Start Guide

1 Installation

Import the library directly in your HTML or JavaScript:

<script type="module">
  import { CodeSandbox } from './isolatex.js';
</script>

2 Basic Usage

Create a sandbox and execute code:

const sandbox = new CodeSandbox({
  timeout: 5000,
  validateSyntax: true,
  logNetworkRequests: true
});

await sandbox.init();

const result = await sandbox.execute(`
  console.log('Hello from IsolateX!');
  const data = await fetch('https://api.github.com/repos/MarketingPipeline/Termino.js');
  console.log(await data.json());
`);

console.log(result.logs); // Array of console outputs
console.log(result.executionTime); // Execution time in ms

3 Configuration Options

timeout
number (default: 30000)

Maximum execution time in milliseconds

validateSyntax
boolean (default: true)

Enable syntax validation before execution

logNetworkRequests
boolean (default: false)

Log all fetch and XHR requests to console

captureWindowErrors
boolean (default: true)

Capture and report window-level errors

4 Event Monitoring

Listen to sandbox lifecycle events:

sandbox.on('execution:start', ({ id, code }) => {
  console.log(`Starting execution ${id}`);
});

sandbox.on('execution:complete', ({ id, result }) => {
  console.log(`Completed in ${result.executionTime}ms`);
}); 

sandbox.on('execution:error', ({ id, error }) => {
  console.error(`Execution failed: ${error}`);
});

sandbox.on('execution:fs', ({ method, filename, data }) => {
  console.error(`Execution failed: ${error}`);
});

sandbox.on('execution:stdout', ({ type, args }) => {
  console.log(type, args);
});

sandbox.on('execution:timeout', ({ id }) => {
  console.warn(`Execution ${id} timed out`);
});
